# Figma Screen Design Guide

How to design full product screens using the Agentic design system in Figma.

---

## Contents

| File | What it covers |
|---|---|
| `artboard-setup.md` | Creating frames, applying grid styles, breakpoints, page organisation |
| `annotation-guide.md` | Marking spacing, component names, states, and handoff notes |
| `screen-flow.md` | Connecting screens, naming pages, flow conventions |

---

## Prerequisites

- Figma file: `YWfTOUTpFZ0BNxHobfUqme`
- All 35 components are built and token-bound in the file
- Component directory: `Machine Readable/component-directory.md`
- Token reference: `agentic-design-system.md`

---

## Quick start

1. Create a frame at the correct size → `artboard-setup.md`
2. Apply the Grid Style → `artboard-setup.md`
3. Drop in components from the library → `component-directory.md`
4. Annotate for handoff → `annotation-guide.md`
5. Connect screens into a flow → `screen-flow.md`
